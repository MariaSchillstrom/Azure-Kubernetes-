### 2. Push till ACR

**Varför ACR?**\
Min Docker image finns just nu endast lokalt på datorn. AKS (Azure Kubernetes Service) kan inte komma åt min lokala dator, därför behöver imagen finnas i molnet. ACR (Azure Container Registry) fungerar som ett molnbaserat bildbibliotek där Kubernetes kan hämta imagen.

### 2.1 Flöde

Lokal dator (Docker image)\
↓ PUSH\
ACR (Lagring i Azure)\
↓ PULL\
AKS (Kubernetes kör appen)

### 2.2 Steg som utfördes

**1. Skapade Resource Group:**

```bash
az group create --name mysvampsidaRG --location westeurope
```

**2. Skapade ACR:**

```bash
az acr create --resource-group mysvampsidaRG --name svampapp --sku Basic
```

**3. Loggade in i ACR:**

```bash
az acr login --name svampapp
```

### 2.3 Problem: ACR Tasks blockerat

När jag försökte bygga och pusha imagen direkt i Azure med:

```bash
az acr build --registry svampapp --image svampapp:v1 .
```

Fick jag felet:

```
(TasksOperationsNotAllowed) ACR Tasks requests for the registry svampapp 
are not permitted.
```

**Orsak:**\
Azure for Students-subscriptionen blockerar ACR Tasks (Azure's tjänst för att bygga Docker images i molnet).

**Lösning:**\
Byggde imagen lokalt och pushade manuellt istället:

**4. Tagga imagen för ACR:**

```bash
docker tag svampapp-web:latest svampapp.azurecr.io/svampapp:v1
```

**5. Pusha till ACR:**

```bash
docker push svampapp.azurecr.io/svampapp:v1
```

\[Bild: docker push resultat]

### 2.4 Resultat

✅ Docker imagen finns nu i `svampapp.azurecr.io/svampapp:v1` och kan användas av AKS.
