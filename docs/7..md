### **7. ArgoCD (GitOps)**



Nu är det dags att ordna så att vår applikation deployas automatiskt, vid eventuella ändringar.Vad är då ArgoCD\`? Jag fick för mig att det är ungefär som CI/CD, vilket det är men ändå inte.&#x20;

ArgoCD är enbart CD delen, om man jämför med CI/CD.Vill man även ha CI delen, för detta projekt så behöver man lägga till GitHub Actions.

### 7.1 Installera ArgoCD

**Skapa namespace:**

```bash
 kubectl create namespace argocd
```

**Installera ArgoCD:**&#x20;

```bash
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
```

**Vänta tills pods är igång:**&#x20;

```bash
kubectl get pods -n argocd --watch
```

### 7.2 Exponera ArgoCD

**Ändra till LoadBalancer:**&#x20;

```bash
kubectl patch svc argocd-server -n argocd -p '{"spec": {"type": "LoadBalancer"}}'
```

**Hämta extern IP:**&#x20;

```bash
kubectl get svc argocd-server -n argocd
```

**Resultat:** ArgoCD tillgängligt via extern IP&#x20;

**Kort förklarat**

* **Git + ArgoCD** = du ändrar YAML → commit & push → ArgoCD syncar mot klustret.
* **Utan ArgoCD** = du ändrar YAML → _du själv_ kör `kubectl apply`/`kubectl scale` varje gång.
