### 6. Nginx Ingress Controller

I det här steget installerar vi Nginx Ingress Controller.&#x20;

Syftet med detta är att ha en Load Balancer för flera appar, även om jag bara har en. Vi kan alltså redan nu förbereda oss på att eventuellt skapa flera appar.&#x20;

Exempel;

* **Huvudsidan** - Visa och hantera svampar
* **Bloggen** - Artiklar om svampplockning
* **API - JSON** - data för andra appar.

Det här gjorde mig en aning förbryllad, tyckte det var väldigt rörigt. Hade väldigt svårt att få ihop varför man ska ha 3 applikationer på samma IP istället för att bara ha allt på en applikation.&#x20;

Men efter mycket om och men så förstod jag hyfsat.&#x20;

#### 6.1 Installera Nginx Ingress Controller

```
kubectl apply -f https://raw.githubusercontent.com/kubernetes/ingress-nginx/controller-v1.8.2/deploy/static/provider/cloud/deploy.yaml
```

#### 6.2 Vänta tills det är klart&#x20;

<pre><code><strong>kubectl get pods -n ingress-nginx --watch
</strong></code></pre>

<figure><img src=".gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>



#### 6.3 Kontrollera att Ingress controller har en extern IP

```bash
kubectl get service -n ingress-nginx
```



<figure><img src=".gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>

#### 6.4 Skapa Ingress-regel

**Skapa ny fil i manifests**

```
manifests/svampapp-ingress.yaml 
```

#### 6.5 Ändra i din svampapp-service till Clusterip

**Från**&#x20;

```yaml
spec:
  type: LoadBalancer
```

**Till**

```yaml
spec:
  type: ClusterIP
```

Varför;&#x20;

* Tidigare hade svampapp extern IP (20.61.31.172)&#x20;

- [x] Nu; Nginx Ingress har extern IP (13.81.190.228)
- [x] Svampapp blir intern, bara nåbar via ingress

#### 6.6 Applicera ändringarna

```bash
kubectl apply -f manifests/
```
