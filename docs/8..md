### &#x38;**. Docker Build + Push till ACR via GitHub Actions**

I detta steg automatiserar vi hela CI/CD-flödet så att varje kod-ändring automatiskt bygger och deployer applikationen.

**Flödet:**

```
Kod-ändring → Git push → GitHub Actions bygger imagen → Pushar till ACR → ArgoCD deployer
```

### **8.3 Skapa GitHub Actions Workflow**

**Skapa fil:** `.github/workflows/docker-build-push.yml`

**Innehåll:**

**OBS!! Glöm inte att uppdatera "deployment.yml från&#x20;**_**:v1**_**&#x20;till&#x20;**_**latest**_**&#x20;(se steg 9.5) annars kommer nya images inte användas! Detta glömde jag givetvis.**&#x20;

```yaml
name: Build and Push Docker Image

on:
  push:
    branches:
      - dev
    paths:
      - 'svamp-app/**'
      - '.github/workflows/docker-build-push.yml'

jobs:
  build-and-push:
    runs-on: ubuntu-latest
    
    steps:
    - name: Checkout code
      uses: actions/checkout@v3
    
    - name: Log in to Azure
      uses: azure/login@v1
      with:
        creds: ${{ secrets.AZURE_CREDENTIALS }}
    
    - name: Log in to ACR
      run: |
        az acr login --name svampapp
    
    - name: Build Docker image
      run: |
        cd svamp-app/webapp/Svampsidan
        docker build -t svampapp.azurecr.io/svampapp:${{ github.sha }} .
        docker tag svampapp.azurecr.io/svampapp:${{ github.sha }} svampapp.azurecr.io/svampapp:latest
    
    - name: Push to ACR
      run: |
        docker push svampapp.azurecr.io/svampapp:${{ github.sha }}
        docker push svampapp.azurecr.io/svampapp:latest
```

**Pusha till GitHub:**



```bash
git add .github/workflows/docker-build-push.yml
git commit -m "Add Docker build and push workflow"
git push origin dev
```

### **8.5 Uppdatera Deployment för CI/CD**

**VIKTIGT STEG:** För att Kubernetes ska hämta nya images måste deployment använda `:latest`-taggen. Detta glömde jag så fick det inte att fungera de två första försöken.&#x20;

**Öppna:** `manifests/svampapp-deployment.yaml`

**Ändra från:**

```yaml
image: svampapp.azurecr.io/svampapp:v1
```

**Till:**

```yaml
image: svampapp.azurecr.io/svampapp:latest
```

**Pusha:**

```bash
git add manifests/svampapp-deployment.yaml
git commit -m "Update deployment to use latest tag"
git push origin dev
```
